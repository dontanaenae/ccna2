Exercise 1: Subnet for 8 offices using the network address fd00:1::/64
CAI METHOD

C: 8 offices = 3 bits
A: /64 + 3bits = /67 (5 butas, 1st Hex, 2i)
I: EXPAND FIRST = fd00:0001:0000:0000:0000:0000:0000:0000
		=		     :0000: (1st office)(always start with 0)
				     :0002: (2nd office)
				     :0004: (all the way to 64th office)

Exercise 3: Subnet for 52 offices using the network address fd00:3:0:33::/112
Determine the 6th Subnet.

C: 52 = 6bits

I: Expand First = fd00:0003:0000:0033:0000:0000:0000:0000 /118
First Office	= fd00:0003:0000:0033:0000:0000:0000:0000 /118
Second Office	= fd00:0003:0000:0033:0000:0000:0000:0400 /118
Third Office	= fd00:0003:0000:0033:0000:0000:0000:0800 /118
Fourth Office	= fd00:0003:0000:0033:0000:0000:0000:0c00 /118
Fifth Office	= fd00:0003:0000:0033:0000:0000:0000:1000 /118
Sixth Office	= fd00:0003:0000:0033:0000:0000:0000:1400 /118

Network    : fd00:0003:0000:0033:0000:0000:0000:1400 /118 
First Valid: fd00:0003:0000:0033:0000:0000:0000:1401 /118

Unicast: One is to one
Multicast: One to many
Broadcast: To all
Anycast:One to the nearest

Last Anycast Address - /120 and below 
/121 - /128 = NO MORE ANYCAST

Network    :  fd00:0003:0000:0033:0000:0000:0000:1400 /118 
First Valid:  fd00:0003:0000:0033:0000:0000:0000:1401 /118
NON ANYCAST:  fd00:0003:0000:0033:0000:0000:0000:177f
FIRST ANYCAST:fd00:0003:0000:0033:0000:0000:0000:1480
Last Valid :  fd00:0003:0000:0033:0000:0000:0000:17ff /118
Not Net    : fd00:0003:0000:0033:0000:0000:0000:1800 /?

ANYCAST = CONSTANT
NON Anycast  : Last 2 values should always be "7f" (-1 First Anycast)
First Anycast: Last 2 values should always be "80" (-1 Last Anycast)
Last Anycast : Last 2 values should always be "ff" (-1 Not Network)

Process: Get Network >> Get Not Network >> Get LAST ANYCAST >> Get NON ANYCAST >> GET FIRST ANYCAST
